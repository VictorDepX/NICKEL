# GUI do NICKEL em React + shadcn/ui + AI Elements — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Substituir a GUI em JS puro (`nickel/ui/static/`) por uma SPA React que segue o design system aprovado, usando shadcn/ui e AI Elements, servida pelo mesmo FastAPI sem exigir Node no PC.

**Architecture:** Código-fonte em `web/` (Vite + React 19 + TypeScript + Tailwind v4). `npm run build` gera os arquivos em `nickel/ui/static/` (commitados), então o PC só faz `git pull`. Dados vêm das rotas atuais do FastAPI (`/api/*`) e do SSE `/api/events/stream`; a lógica de fases do Monitor (`monitor-core.js`) é portada para TypeScript sem mudar o comportamento, com os testes atuais portados para Vitest.

**Tech Stack:** Vite, React 19, TypeScript, Tailwind CSS v4, shadcn/ui (new-york, tokens próprios), AI Elements (`https://registry.ai-sdk.dev/<item>.json`), lucide-react, @tanstack/react-query, react-router (hash), recharts (via `@shadcn/chart`), @fontsource-variable/geist e geist-mono, Vitest + Testing Library.

**Spec:** canvas de design aprovado (https://claude.ai/artifact/BTd5MYz9Mc7PF2FswCPdvN) — tokens em `docs/design/nickel.css` (cópia de `styles/nickel.css` do canvas), telas Início, Conversa, Monitor, Lembretes, Memória, Conectores, Conversa no celular, e estados da conversa.

## Global Constraints

- Idioma da interface: português do Brasil, frases curtas, sem emoji. Nomes de ferramentas (`reminder_create`) aparecem em fonte mono.
- Tokens: os valores de `docs/design/nickel.css` viram as variáveis CSS do shadcn em `web/src/styles/globals.css` (mesmos nomes: `--background #09090b`, `--foreground #f4f4f5`, `--card #121317`, `--popover/--sidebar #0c0d10`, `--secondary #1a1b20`, `--muted #18191d`, `--muted-foreground #a1a1aa`, `--subtle-foreground #8b8b94`, `--border #24262d`, `--input #2a2c33`, `--primary #f4f4f5`, `--primary-foreground #09090b`, `--accent #16202b`, `--accent-foreground #c9e9ff`, `--ring #9cd6ff`, `--success #4ade80`, `--warning #fbbf24`, `--destructive #f87171`, fases `--phase-thinking #b9a7f5`, `--phase-tool #e7b16b`, `--phase-speaking #fb923c`, `--phase-listening/answering #9cd6ff`). Só tema escuro.
- Fontes: Geist e Geist Mono empacotadas (fontsource), sem Google Fonts em tempo de execução (o NICKEL é local).
- Esfera: `web/public/esfera.gif` (o GIF aprovado), exibido com `mix-blend-mode: screen`, anel colorido pela fase; parado quando `prefers-reduced-motion`.
- Layout: menu lateral à esquerda (aberto/recolhido em ícones, estado salvo em localStorage) e cápsula de recursos à direita (recolhida por padrão, expande para painel) nas telas Início e Conversa.
- Acessibilidade: contraste ≥ 4,5:1, alvos de toque ≥ 44 px nos controles principais, `aria-label` em botões só com ícone, foco visível (`--ring`), `prefers-reduced-motion` respeitado.
- Build: `cd web && npm ci && npm run build` escreve em `nickel/ui/static/` (index.html + assets/ com hash). O FastAPI continua servindo `/` → `index.html` e `/static/*`; `Cache-Control: no-cache` continua valendo.
- Nenhuma rota do backend muda de contrato. Rota nova permitida: `POST /api/reminders` (Tarefa 7).
- Testes: `python -m pytest -q` e `cd web && npm test` passam; pyflakes limpo; `npm run build` sem erro de tipo (`tsc -b`).
- Commits com as linhas finais `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` e `Claude-Session: https://claude.ai/code/session_01QY5zMTLxiXXFz8B1MGn1MH`. Branch `v2`.

## Review Focus

- SSE caindo e voltando: a linha de status e a esfera não podem ficar presas em "Pensando" — reconectar e reidratar o estado pelo replay.
- Resposta longa com markdown (listas, código, links): renderizada sem HTML cru e sem quebrar o layout.
- Confirmação pendente: aparece na conversa e no Início; confirmar ou cancelar atualiza os dois lugares e a resposta do NICKEL chega.
- Backend fora do ar (llama-server desligado): erro visível na conversa e no conector "Modelo", sem tela branca.
- Tela estreita (390 px): menu vira gaveta, cápsula vira botão no cabeçalho, nada de rolagem horizontal.
